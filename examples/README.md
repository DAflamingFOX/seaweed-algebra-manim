# Examples

This folder contains example jupyter notebooks showcasing the usage of the library, additionally, it contains the python file to generate the animations shown in the [main README file](../README.md).

To view or play with the examples you can simply click on the file, then click the ![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg) button!

The first time you run the notebook it will take a long time (~5 minutes) as it has to install all the packages required for manim.
It may also ask you to restart the kernel, this is to be expected.
