# Examples

This directory contains interactive examples for `manim-meander-winding`.

## Contents

- **`walkthrough.ipynb`**: Interactive Jupyter notebook walking through each of the five elementary meander winding moves and demonstrating full wind-down with inline Manim cell rendering.

## Running the Notebook

To run the notebook with Jupyter:

```bash
uv run --with jupyter jupyter lab walkthrough.ipynb
```

or with pip in your virtual environment:

```bash
pip install jupyterlab
jupyter lab walkthrough.ipynb
```
