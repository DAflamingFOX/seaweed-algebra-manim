# Examples

This directory contains interactive examples for `seaweed-algebra-manim`.

## Contents

- **`example.ipynb`**: Interactive Jupyter notebook walking through each of the five elementary meander winding moves and demonstrating full wind-down with inline Manim cell rendering.

## Running the Notebook

To run the notebook with Jupyter:

```bash
uv run --with jupyter jupyter lab example.ipynb
```

or with pip in your virtual environment:

```bash
pip install jupyterlab
jupyter lab example.ipynb
```
